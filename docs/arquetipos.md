## 1. Qué es un arquetipo

Un **arquetipo** es la plantilla de diseño de una carta: una combinación
recurrente de stats, keyword y alcance que define su rol en partida. Sirve para
clasificar cartas y familias nuevas sin reinventar el vocabulario, y para
auditar que el coste paga lo que la carta hace (ver `docs/guia-de-balance.md`).

| Familia | Formas | Rol mecánico dominante |
| --- | --- | --- |
| Asterión | c3 -> a2 -> a3 | Muro con escalado: base sólida, rama de Embestida y rama de control (Exilio). |
| Dédalo | a7 -> a10 -> talos | Generación y utilidad: Invocar, Exilio, finisher de área. |
| Mortales | c1 -> fuego -> muros | Soporte de familia: rama de Fortalecer (fuego) y rara de Bloqueo (muros). |
| Sátiro | c2 -> sat_cortejo / sat_pan | Ramas de especialización desde la base: buffer de equipo (cortejo) o control por exilio (pan). |
| Medusa | b0-b10 | Token swarm (Serpientes), Gloria por tablero y control (Exilio, Reflejo). |
| Eventos/Heroes | c4, c8, e1-e5 | Efectos puntuales: Gloria, Descuento, Destruir, Bloqueo pesado. |
